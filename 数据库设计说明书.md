# 智能项目管理系统 - 数据库设计说明书

## 1. 引言

### 1.1 编写目的
本文档是智能项目管理系统的数据库设计说明书，旨在描述数据库的表结构设计、索引设计、约束设计和数据字典，为数据库创建和维护提供指导。

### 1.2 数据库环境
- **数据库类型**：MySQL 8.0
- **字符集**：utf8mb4
- **排序规则**：utf8mb4_unicode_ci
- **存储引擎**：InnoDB
- **数据加密**：采用数据库透明加密（TDE）或等效数据库/磁盘透明加密能力；金额字段保留 `DECIMAL` 类型，便于统计、校验和排序

## 3. 表结构详细设计

### 3.1 用户表 (sys_user)

```sql
CREATE TABLE sys_user (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(255) NOT NULL COMMENT '密码(BCrypt加密)',
    name VARCHAR(50) NOT NULL COMMENT '姓名',
    phone VARCHAR(20) NOT NULL COMMENT '手机号',
    email VARCHAR(100) COMMENT '邮箱',
    role VARCHAR(20) NOT NULL COMMENT '角色(admin/business/finance/pm)',
    dept VARCHAR(50) COMMENT '部门',
    status TINYINT NOT NULL DEFAULT 1 COMMENT '状态(0禁用/1启用)',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    INDEX idx_username (username),
    INDEX idx_role (role),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

### 3.2 角色表 (sys_role)

```sql
CREATE TABLE sys_role (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '角色ID',
    role_name VARCHAR(50) NOT NULL COMMENT '角色名称',
    role_code VARCHAR(50) NOT NULL UNIQUE COMMENT '角色编码',
    permissions TEXT COMMENT '权限列表(JSON格式)',
    status TINYINT NOT NULL DEFAULT 1 COMMENT '状态(0禁用/1启用)',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    INDEX idx_role_code (role_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='角色表';
```

### 3.3 数据字典表 (sys_dict)

```sql
CREATE TABLE sys_dict (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '字典ID',
    dict_type VARCHAR(50) NOT NULL COMMENT '字典类型',

```

### 3.4 操作日志表 (sys_log)

### 3.5 项目信息表 (project_info)

```sql
CREATE TABLE project_info (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '项目ID',
    project_no VARCHAR(20) NOT NULL UNIQUE COMMENT '项目编号(PRJ-YYYY-NNNN)',
    name VARCHAR(200) NOT NULL COMMENT '项目名称',
    customer VARCHAR(200) NOT NULL COMMENT '客户名称',
    amount DECIMAL(15,2) NOT NULL DEFAULT 0 COMMENT '合同金额',
    contract_no VARCHAR(50) COMMENT '合同编号',
    sign_date DATE COMMENT '签订日期',
    project_type VARCHAR(50) COMMENT '项目类型',
    pm_id INT COMMENT '项目经理ID',
    start_date DATE COMMENT '预计开始日期',
    end_date DATE COMMENT '预计结束日期',
    description TEXT COMMENT '项目描述',
    extra_cost DECIMAL(15,2) DEFAULT 0 COMMENT '后期支出',
    cost_desc VARCHAR(500) COMMENT '支出说明',
    status VARCHAR(20) NOT NULL DEFAULT 'draft' COMMENT '状态(draft/pending/approved/active/closed/terminated/framework)',
    balance_status VARCHAR(20) DEFAULT '待回款' COMMENT '尾款状态(已结清/部分回款/待回款)',
    create_by INT COMMENT '创建人ID',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    INDEX idx_project_no (project_no),
    INDEX idx_customer (customer),
    INDEX idx_status (status),
    INDEX idx_pm_id (pm_id),
    INDEX idx_create_by (create_by),
    INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='项目信息表';
```

### 3.6 合同信息表 (project_contract)

    file_type VARCHAR(10) NOT NULL COMMENT '文件类型(word/pdf)',

    file_size BIGINT COMMENT '文件大小(字节)',

    upload_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '上传时间',

## 4. 索引设计

### 4.1 主键索引
所有表都使用自增ID作为主键。

### 4.2 唯一索引
| 表名 | 索引名 | 字段 | 说明 |
|------|--------|------|------|
| sys_user | uk_username | username | 用户名唯一 |
| sys_role | uk_role_code | role_code | 角色编码唯一 |
| sys_dict | uk_type_code | dict_type, dict_code | 字典类型+编码唯一 |
| project_info | uk_project_no | project_no | 项目编号唯一 |
| project_invoice | uk_invoice_no | invoice_no | 发票号码唯一 |

### 4.3 普通索引
| 表名 | 索引名 | 字段 | 说明 |
|------|--------|------|------|
| project_info | idx_customer | customer | 客户查询 |

## 9. 性能优化

### 9.1 索引优化
- 频繁查询字段建立索引
- 组合查询使用联合索引
- 避免索引失效

### 9.2 查询优化
- 避免SELECT *
- 分页查询使用LIMIT
- 大数据量使用流式查询

### 9.3 并发与锁策略
- 开票金额校验、回款金额校验必须在数据库事务中执行
- 开票登记时对对应 `project_info` 行执行 `SELECT ... FOR UPDATE`，锁定项目后再汇总当前开票金额并写入发票
- 回款登记时对对应 `project_invoice` 行执行 `SELECT ... FOR UPDATE`，锁定发票后再汇总该发票回款金额并写入回款
- 事务隔离级别建议使用 MySQL InnoDB 默认 `REPEATABLE READ`，关键金额校验依赖行锁避免并发越界

### 9.4 表优化
- 定期OPTIMIZE TABLE
- 合理设置字段类型
- 避免过度范式化
